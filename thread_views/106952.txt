*--- opening post by jeppenodgaard (2026-04-08 05:51:52+00:00)
Remove meta file check. If `KERNEL_META_PATH` is not found the value is `""`. This does not trigger the check.

Also `KERNEL_META_PATH` is set even if `CONFIG_BUILD_OUTPUT_META` is not, but the file does not exist. Therefore split up `YAMLError` and `FileNotFoundError` and move the `CONFIG_BUILD_OUTPUT_MEAT` error log to the latter.

*--- Copilot (2026-04-15 13:55:32+00:00)
`setupDocuments()` assumes `self.metaFile` always exists, but it’s only set in `getCacheFile()` when `parseCMakeCacheFile()` returns a truthy dict. If the CMakeCache can’t be read/parsed (parse returns `{}`), this will raise `AttributeError` at `open(self.metaFile)` which isn’t caught. Initialize `self.metaFile` to "" in `__init__` (or always set it in `getCacheFile()` even on parse failure) and keep the missing-file path handled as a normal `FileNotFoundError`/falsy check.

*--- Copilot (2026-04-15 13:55:32+00:00)
The `FileNotFoundError` message doesn’t include which meta file path couldn’t be opened (and `FileNotFoundError` can occur for reasons other than CONFIG_BUILD_OUTPUT_META being off, e.g. stale build dir). Include `self.metaFile` in the error (and optionally distinguish empty path vs missing file at a non-empty path) to make failures actionable.
