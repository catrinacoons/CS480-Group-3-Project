This PR adds a sensor driver for the BH1790 Heart Rate Sensor IC ([Datasheet](https://fscdn.rohm.com/en/products/databook/datasheet/ic/sensor/pulse_wave/bh1790glc-e.pdf)).

I have used the BH1750 implementation as a starting point for the build setup and other sensors for implementation. Not all registers and configuration has been implemented. That can be done as part of this PR or as a follow up PR.

A sample has been added which is combined with the MAX30101 heart rate sensor sample. I have separated this into a second commit for the time being so that it can be split into another PR if necessary.

I have tried to follow the contribution guidelines and code style guides, but might have missed some things in the meantime.

Happy to make changes as guided.

Thanks,

*--- MagpieEmbedded (2025-04-08 08:41:31+00:00)
Hi @yperess, thanks for reviewing. I have made fixes to the code as you requested above.

Regarding the channels, I chose this to match the other heart rate sensor currently in Zephyr, the MAX30101, in returning data on the Green light channel. The BH1790 also provides "OFF" data which is measuring ambient light. Neither channel on the BH1790 is associated directly with lumens according to the datasheet but this seemed like the best place to put it.

The sensor only returns light readings, it does not return heart rate data directly. That requires further data analysis at the application level.

This seemed like the best compromise to me based on what is already in Zephyr. I would be happy to make further changes to implement this in a better way.

Thanks,

Tim
