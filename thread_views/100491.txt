*--- Copilot (2025-12-04 05:23:47+00:00)
`$build_cmd` is executed as a single variable (`if ! $build_cmd; then`) after being constructed with `-DCONFIG_TEST_GAP_CENTRAL_ADDRESS="${virtual_addresses[1]}"`. Because quotes inside the variable are not preserved during word splitting, a crafted `virtual_addresses[1]` value containing shell metacharacters (e.g., `"; rm -rf / #`) can break out of the intended flag and inject arbitrary commands. Construct the command as an array and pass the address as a separate, safely quoted argument, e.g.,

```bash
local addr=${virtual_addresses[1]}
west build -b native_sim tests/bluetooth/classic/gap_discovery -d "$build_dir" -DCONFIG_TEST_GAP_PERIPHERAL=y -DCONFIG_TEST_GAP_CENTRAL_ADDRESS="$addr"
```

or use `printf '%q'` to escape the value and avoid executing a variable as a command.
```suggestion
    local addr="${virtual_addresses[1]}"

    log_info "Executing build command: west build -b native_sim tests/bluetooth/classic/gap_discovery -d \"$build_dir\" -DCONFIG_TEST_GAP_PERIPHERAL=y -DCONFIG_TEST_GAP_CENTRAL_ADDRESS=\"$addr\""

    # Execute the build command safely
    if ! west build -b native_sim tests/bluetooth/classic/gap_discovery -d "$build_dir" -DCONFIG_TEST_GAP_PERIPHERAL=y -DCONFIG_TEST_GAP_CENTRAL_ADDRESS="$addr"; then
```
