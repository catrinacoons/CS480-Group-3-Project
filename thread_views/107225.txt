*--- Copilot (2026-04-16 08:26:10+00:00)
`nominal_addend` is computed assuming `ref_clk_hz` is strictly greater than `PTP_CLOCK_NXP_ENET_QOS_PTPCLK_HZ`, but the code never enforces that. If the reference clock is <= 50 MHz, the addend computation will overflow/truncate (uint32_t cast) and produce an incorrect rate. Add a runtime check (and clear error return/log) before computing the addend, and consider validating `snsinc` as well.

*--- Copilot (2026-04-16 08:26:10+00:00)
The busy-wait loops that poll TSINIT/TSUPDT/TSADDREG clear bits have no timeout, so a clock-domain/configuration issue could hang the system forever. Please add a bounded wait (e.g., using `k_busy_wait()` chunks with a max duration like the ENET QoS DMA reset helper) and return an error if the bit never clears.

*--- Copilot (2026-04-16 08:26:10+00:00)
`memset(... * frags_count)` resets descriptors based on fragment count, but TX now uses `data->tx.num_descs` descriptors (potentially half as many). This is harmless but does extra work; consider clearing only the descriptors that will be used (or compute `num_descs` earlier and use that consistently).
