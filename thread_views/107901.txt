*--- qbx11 (2026-04-25 17:36:20+00:00)
This is the pattern tracked in #65974 as incorrect. `-errno` is not a specific value. 
Possible fixes IMO:

1.
```
@return 0 on success, or a negative errno code on failure.
```
(as suggested in https://github.com/zephyrproject-rtos/zephyr/issues/65974#issuecomment-4245521599)

2.
```
@retval 0 on success.
@return Negative errno code on failure.
```
3.
```
@retval 0 Operation completed successfully.
@return Negative errno code on failure.
```
