Add initial support for openFPGALoader to flash FPGA boards. This is flash support only, no debug support.

*--- Copilot (2026-09-13 21:35:34+00:00)
This runner exposes a tool-specific `--offset`, so it can write an image at an arbitrary address, but leaving `flash_addr` false suppresses west's shared `--dt-flash` option (see `core.py:627-634`). A build whose code partition/load offset is non-zero is therefore sent without that offset unless the user manually duplicates the build configuration. Advertise `flash_addr=True` and translate `--dt-flash` into the openFPGALoader offset, with a defined precedence for an explicit `--offset`.
