TITLE: Bluetooth: Controller: nRF54L: Add dual-timer support

*--- opening post by cvinayak (2026-05-20 19:19:24+00:00)
Add support for using NRF_TIMER00 in the MCU power domain as the EVENT_TIMER for event timing, while keeping NRF_TIMER10 in the Radio power domain as the SW_SWITCH_TIMER for tIFS switch timings.

This is enabled when CONFIG_BT_CTLR_SW_SWITCH_SINGLE_TIMER=n on SOC_COMPATIBLE_NRF54LX. The default remains single-timer (TIMER10 for both), preserving backward compatibility.

Cross-domain DPPI connections use three PPIB bridges:
  PPIB11/PPIB21: Radio <-> Peripheral (GRTC -> NRF_TIMER10, existing)
  PPIB00/PPIB10: MCU <-> Radio (NRF_TIMER00 <-> Radio peripherals)
  PPIB01/PPIB20: MCU <-> Peripheral (GRTC -> NRF_TIMER00, new)

DPPIC00 channels 0-5 are assigned for the six EVENT_TIMER connections:
  ch 0: GRTC -> NRF_TIMER00 START (via PPIB20/PPIB01)
  ch 1: NRF_TIMER00 COMPARE -> Radio TXEN/RXEN (via PPIB00/PPIB10)
  ch 2: Radio READY -> NRF_TIMER00 CAPTURE (via PPIB10/PPIB00)
  ch 3: Radio ADDRESS -> NRF_TIMER00 CAPTURE (via PPIB10/PPIB00)
  ch 4: NRF_TIMER00 COMPARE -> Radio DISABLE (via PPIB00/PPIB10)
  ch 5: Radio END -> NRF_TIMER00 CAPTURE (via PPIB10/PPIB00)

Timer prescaler values:
  NRF_TIMER00 (HFPLL 128 MHz): prescaler 7 -> 1 MHz resolution
  NRF_TIMER10 (HFXO 32 MHz):  prescaler 5 -> 1 MHz resolution

DPPIC00 and PPIB bridge channel reservations are declared in bt_ctlr_used_resources.h and mapped to nrfx resource tracking in nrfx_reserved_resources.h.

Requires CONFIG_BT_CTLR_NRF_GRTC (default y on nRF54L) since the PPIB01/PPIB20 bridge for GRTC -> NRF_TIMER00 is only configured in the GRTC event path.

*--- Copilot (2026-05-21 04:25:08+00:00)
In dual-timer mode (EVENT_TIMER = NRF_TIMER00), the event-timer start path relies on the GRTC->TIMER00 cross-domain bridge configuration in hal_event_timer_start_ppi_config(). If CONFIG_BT_CTLR_NRF_GRTC is not enabled, the RTC-based path will be used and the required PPIB01/PPIB20 bridging to TIMER00 is not configured, which would make the timing wiring incorrect. Add the same compile-time guard/error used in radio_nrf54lx.h to prevent building dual-timer mode without CONFIG_BT_CTLR_NRF_GRTC.

*--- Copilot (2026-05-21 04:25:09+00:00)
`#define EVENT_TIMER_ID 00` introduces an octal literal (leading zero) and can be confusing in preprocessor numeric comparisons. Consider keeping EVENT_TIMER_ID as `0` and directly defining `EVENT_TIMER` as `NRF_TIMER00` (or introduce a separate token/macro for the `00` suffix used only for identifier concatenation).
