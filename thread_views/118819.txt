TITLE: drivers: usb: uhc: max3421e: chunk OUT data by the endpoint's mps

*--- opening post by goblej (2026-09-11 10:39:07+00:00)
`max3421e_xfer_data()` limited each OUT packet to `MAX3421E_MAX_EP_SIZE` instead
of the endpoint's maximum packet size, overrunning an endpoint whose mps is
smaller.

The IN path is already fixed by #118750, so this PR is now reduced to the same
defect on the OUT side. Reworked per review to pass the transfer rather than the
endpoint address, so both `ep` and `mps` are available.

Not exercised on hardware: enumeration uses no OUT data stage, so the bug is
latent there and is only reached by a bulk OUT or a class request to such a
device.
