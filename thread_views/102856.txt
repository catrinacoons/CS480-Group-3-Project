The namespace UUID has an incorrect value. According to RFC 9562 Appendix A.4, the well-known namespace ID for URLs is `6ba7b810-9dad-11d1-80b4-00c04fd430c8` (note `10` not `11` after `b8`). This is confirmed by both the test code and sample code in the repository.
```suggestion
   uuid_from_str("6ba7b810-9dad-11d1-80b4-00c04fd430c8", &ns_uuid);
```
