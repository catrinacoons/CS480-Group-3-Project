Adds a new Zephyr sensor driver for the MaxBotix MB7040 ultrasonic rangefinder.

The driver uses I2C communication to read range data from the sensor and exposes it via the Zephyr sensor API. 

Functionality was tested on an esp32-s3.

*--- ww3ak (2025-07-07 15:26:32+00:00)
Sure! The semaphore is used to wait until the sensor finishes its measurement (either notified by the set status GPIO or using the default timeout). When I send the range command, I wait on the semaphore, and the interrupt callback (triggered by the status GPIO falling edge) gives the semaphore to signal that data is ready. This way, we avoid busy-waiting and only continue once the sensor is done. I hope this helps!
