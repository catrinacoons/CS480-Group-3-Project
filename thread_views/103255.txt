*--- Copilot (2026-02-04 22:30:16+00:00)
The comparison operator should be `!=` (numeric inequality) instead of `ne` (string inequality) since `mbswidth()` returns a numeric value representing the display width. While Perl's automatic type conversion makes this work, using the correct numeric comparison operator is more semantically accurate and follows best practices.
```suggestion
			if (mbswidth($oldindent) != mbswidth($newindent)) {
```
