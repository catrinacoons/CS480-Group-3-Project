*--- Copilot (2026-05-06 23:52:38+00:00)
`arduino,uno-adc` nexus expects parent channel indices 0..5 for A0..A5, but this uses `ARDUINO_HEADER_R3_A*` IDs. This will break `io-channel-map` lookups for Arduino ADC overlays. Also, the map references `&adc1`, but this board DTS does not enable/configure `adc1` (RA SoC DTS defaults ADC instances to `status = "disabled"`).

*--- Copilot (2026-05-06 23:52:38+00:00)
`arduino_pwm` maps multiple Arduino pins to `&pwm0`/`&pwm2`/`&pwm3`/`&pwm4`/`&pwm5`, but this board DTS only configures `&pwm1` and provides pinctrl only for `pwm1`. On RA8, these PWM instances are `status = "disabled"` by default, so the Arduino PWM connector mapping will point at disabled/unconfigured devices.

*--- Copilot (2026-05-06 23:52:38+00:00)
`arduino_i2c` is aliased to `&iic1`, but `&iic1` is not set to `status = "okay"` in this board DTS. Since the RA SoC DTS defines IIC controllers as `status = "disabled"` by default, this alias will expose a disabled bus and Arduino I2C overlays/samples will not work until `&iic1` is enabled (and configured as needed).
